# Introduction to Machine Learning

A collection of hands-on Machine Learning practicals implemented in Python. This repository covers foundational supervised and unsupervised learning algorithms, feature preprocessing, NLP vectorization, model evaluation metrics, and data visualization.

## 📋 Practicals Overview

| Practical | Topic / Algorithm | Dataset Used | Key Libraries & Tools |
| :--- | :--- | :--- | :--- |
| **Practical 1** | Linear & Polynomial Regression | Custom 2D numerical arrays | `NumPy`, `SciPy`, `Matplotlib` |
| **Practical 2** | Logistic Regression & Probability Estimation | Custom Tumor Size data & Scikit-Learn `load_diabetes` | `NumPy`, `Pandas`, `Scikit-Learn`, `Matplotlib`, `Seaborn` |
| **Practical 3** | Classification Metrics & Model Evaluation | Scikit-Learn `load_breast_cancer`, Custom binary array (`Dog`/`Not Dog`), `customerchurn.csv` | `NumPy`, `Pandas`, `Scikit-Learn`, `Matplotlib`, `Seaborn` |
| **Practical 4** | K-Nearest Neighbors (KNN) Classification | Custom 2D coordinate points ($k=1$ and $k=5$) | `Scikit-Learn`, `Matplotlib` |
| **Practical 5** | Decision Tree Classifier | `customerchurn.csv` (Telco Customer Churn) | `Pandas`, `NumPy`, `Scikit-Learn` |
| **Practical 6** | Email Spam Detection using Support Vector Machine (SVM) | `spam.csv` (SMS/Email Spam Collection) | `Pandas`, `NumPy`, `Scikit-Learn` (`TfidfVectorizer`, `SVC`, `Pipeline`) |
| **Practical 7** | Sentiment Analysis using Naive Bayes | Custom Movie Reviews dataset | `Scikit-Learn` (`CountVectorizer`, `MultinomialNB`) |
| **Practical 8** | Customer Segmentation using K-Means Clustering | Custom Customer dataset (`Age`, `Income`, `Spending`) | `Pandas`, `Scikit-Learn` (`StandardScaler`, `KMeans`), `Matplotlib` |

## 🛠️ Tools & Technologies Used

* **Language:** Python 3
* **Environment:** Jupyter Notebook / Python Scripts
* **Data Manipulation:** `Pandas`, `NumPy`
* **Machine Learning & Statistics:** `Scikit-Learn`, `SciPy`
* **Data Visualization:** `Matplotlib`, `Seaborn`
